# Contributing to Ghost ESP

## Changelog attribution

All changelog entries follow a strict attribution convention:

- **Untagged lines** are authored by the core maintainer ([@jaylikesbunda](https://github.com/jaylikesbunda)).
- **A trailing `@handle`** credits a guest contributor for that specific line.
- **"Ported from / adapted from"** credits the upstream source a feature was based on, not GhostESP authorship.

When you contribute a change, append `- @yourhandle` to the changelog line for it. If you port or adapt code from another project, name the upstream project and (where possible) its author alongside the credit.
