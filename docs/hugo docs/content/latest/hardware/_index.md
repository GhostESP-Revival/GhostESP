GhostESP sells and maintains its own open-source hardware line, built around off-the-shelf ESP32 modules and open 3D-printed enclosures.

- **[GhostLink P1]({{< relref "ghostlink-p1.md" >}})** is a 3D-printable handheld with a 1.9" display, 5-way nav, microSD, onboard 18650 charging. Buy pre-assembled on [shop.ghostesp.net](https://shop.ghostesp.net), or print and build it yourself: the files, parts list and wiring are all open.
- **[M5Stack AtomS3R]({{< relref "atoms3r.md" >}})** is a compact ESP32-S3 device with screen-button navigation and a Grove port for compatible NFC, sensor, and GPS modules.
