GhostESP supports USB Host and Device mode on ESP32-S3 devices:

- **[Keyboard Control](keyboard)** — Connect a USB keyboard as input for the device
- **[BadUSB](badusb)** — Execute DuckyScript payloads as a USB HID keyboard
- **[USB Keyboard Mode](usb-keyboard-mode)** — Real-time keystroke forwarding from a paired display controller
- **[Mouse Jiggler](mouse-jiggler)** — Keep the host PC awake with periodic mouse movements
