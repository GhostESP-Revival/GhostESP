# GhostESP: Revival

> GhostESP is a Wi-Fi pentesting and multi-protocol wireless security platform for ESP32 devices. Scan Wi-Fi networks, capture handshakes, launch attacks, read NFC tags, learn and transmit IR signals, and more.
