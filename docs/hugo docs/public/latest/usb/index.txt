# USB

> USB Host and Device features for ESP32-S3 devices

---

GhostESP supports USB Host and Device mode on ESP32-S3 devices:
- [Keyboard Control](/latest/usb/keyboard/) — Connect a USB keyboard as input for the device
- [BadUSB](/latest/usb/badusb/) — Execute DuckyScript payloads as a USB HID keyboard
- [USB Keyboard Mode](/latest/usb/usb-keyboard-mode/) — Real-time keystroke forwarding from a paired display controller
- [Mouse Jiggler](/latest/usb/mouse-jiggler/) — Keep the host PC awake with periodic mouse movements
- [USB SD Passthrough](/latest/usb/sd-passthrough/) — Expose the SD card to a host PC as a USB drive
