## Basic Navigation
The app uses a menu-driven interface:
- Up/Down: Navigate through menu items
- OK: Select item or confirm action
- Back: Return to previous menu or cancel
## Common Workflows
### Wi-Fi Handshake Capture
- Navigate to WiFi → Scanning &amp; Probing → Scan APs
- Wait for scan to complete
- Select target network from list
- Go to Packet Capture → EAPOL
- Start capture and wait for handshake
- Export PCAP file when complete
### Beacon Spam Attack
- Navigate to WiFi → Beacon Spam &amp; Attacks → Beacon Spam
- Select spam mode (List, Random, Rickroll, or Custom)
- If using List mode, manage your beacon list first
- Start the spam attack
- Stop when desired
### BLE Device Scanning
- Navigate to Bluetooth → Scanning &amp; Detection → Scan BLE
- Wait for scan to complete
- View discovered devices
- Select device for additional actions (spoof, track, etc.)
### GPS Wardriving
- Ensure GPS module is connected and receiving signal
- Navigate to GPS → Wardriving → WiFi Wardriving
- Start wardriving session
- Drive around to collect data
- Stop and export CSV file with GPS coordinates
## File Management
Use qFlipper or remove the SD card to transfer files to your computer. See [Configuration](/v2.1/flipper-app/configuration/#file-storage) for file storage locations.
