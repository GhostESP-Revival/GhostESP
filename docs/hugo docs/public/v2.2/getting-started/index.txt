# Getting Started

> Initial setup guidance for GhostESP

---

New to GhostESP? Work through these pages in order:
- [Check your board](/v2.2/getting-started/supported-hardware/) - confirm compatibility before flashing.
- [Flash GhostESP](/v2.2/getting-started/installation-guide/) - start with the web flasher, or choose a manual USB or Flipper Zero method.
- [Connect to GhostESP](/v2.2/getting-started/control-methods/) - pick the on-device UI, WebUI, serial CLI, Flipper app, or desktop app.
- [Try your first scan](/v2.2/getting-started/first-scan/) - run a passive Wi-Fi scan to confirm your device works.
After that, configure [SD card storage](/v2.2/getting-started/sd-card/), connect a second board with [GhostLink](/v2.2/getting-started/dual-communication/) or [BLE Bridge](/v2.2/getting-started/ble-bridge/), and review [firmware updates](/v2.2/getting-started/firmware-updates/).
Stuck on something? Start with the [FAQ](/v2.2/getting-started/faq/). If you are adding a module or reconfiguring pins, see [Wiring Modules and Peripherals](/v2.2/getting-started/peripheral-wiring/).
